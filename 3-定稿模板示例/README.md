# 3-定稿模板示例

> 本目录是「AI赛事英雄帖生成器」的**视觉基准成品示例**，展示 Skill 最终产出效果（两种版式）。Skill 的 `build.mjs` 背景层与「竖卡版」逐行对齐。

## 目录

| 目录 | 版式 | 文件 | 说明 |
|---|---|---|---|
| `竖卡版/` | 固定 2:3 竖卡 | `终版HTML.html` + `design-assets/` | **终极定稿**：暗金武侠风，hero 剪影 + 蒙层光晕 + 毛笔大字，Skill 视觉锁定的基准 |
| `长图版/` | 纵向长图 | `英雄招募帖-长图.html` + `design-assets/` | JPG 长图模板（浏览器打开后导出/截图），版式独立，不参与 Skill 生成 |

## 使用方法

- 两个 HTML 都是**完整内联**：字体（woff2）+ 背景图通过同目录 `design-assets/` 引用，需与 html 保持同目录结构。
- 浏览器直接打开 `终版HTML.html` 即见成品海报效果。
