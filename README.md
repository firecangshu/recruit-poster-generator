## 快速开始（对话式 · 形态 A）

1. 说「招募帖 / 英雄帖 / recruit poster」触发 Skill。
2. 选形态 A 对话式（详细）——AI 以武侠人设**逐题发问**（一轮只问一个问题），十问集齐后自动生成。
3. 得到 `招募帖.html`（完整内联 CSS，浏览器直接打开即见海报）。
4. 想换版式：重新跑 `node assets/build.mjs 招募帖-data.json 招募帖.html --template 1.0|2.0|3.0`（默认 2.0）。

## 两种形态

- **形态 A · 对话式（详细）生成（默认）**：口述赛事信息 → AI 生成 HTML 文件交付，最省事。
- **形态 B · 填表式（快速）**：复制填表器到工作区打开预览，浏览器自助填表、实时预览、点「导出 HTML」下载。

## 三套模版

一份数据（`招募帖-data.json`）**内容共用**，仅背景图与版式随模版切换：

| 模版 | 背景 | 版式 |
|---|---|---|
| `1.0` | v1 单人剪影（PNG） | 固定 2:3 竖卡 |
| `2.0` | v2 五人剪影+满月（JPG） | 固定 2:3 竖卡（默认） |
| `3.0` | v2 五人剪影+满月（JPG 长图） | 长图（高度自适应） |

> 生成时 `build.mjs` 会自动把当前模版的背景图 + 毛笔字体拷贝到输出 HTML 同级的 `design-assets/`，换任何工作区都能开箱即用。

## 约束与边界

- **背景锁定**：hero 位置 / 调色 / 蒙层 / 字体 / 配色在模版内已固定，Skill 只改 `.wrap` 内文字。
- **仅产 HTML**：默认不自动渲染 JPG（如需 JPG 用 `assets/render.mjs` 备用渲染）。
- **完全本地**：不联网、不向任何外部端点发送数据、不上传用户内容。
