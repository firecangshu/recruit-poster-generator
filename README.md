# AI赛事英雄帖生成器 · Recruit Poster

> 暗金武侠风「AI赛事英雄帖」一键生成 Skill。两种形态：**对话式（详细）生成**（你口述，我出图）与**填表式（快速）**（浏览器自助填表）。视觉严格对齐终极定稿（固定 2:3 竖卡），只改文字、不染背景、不产 JPG。

## 快速开始（对话式 · 形态 A）

1. 说「招募帖 / 英雄帖 / recruit poster」触发 Skill。
2. 选形态 A 对话式（详细）——AI 以武侠人设**逐题发问**（一轮只问一个问题），十问集齐后自动生成。
3. 得到 `招募帖.html`（完整内联 CSS，浏览器直接打开即见海报）。

## 两种形态

- **形态 A · 对话式（详细）生成（默认）**：口述赛事信息 → AI 生成 HTML 文件交付，最省事。
- **形态 B · 填表式（快速）**：复制填表器到工作区打开预览，浏览器自助填表、实时预览、点「导出 HTML」下载。

## 约束与边界

- **背景锁定**：hero 位置 / 调色 / 蒙层 / 字体 / 配色 / 固定 2:3 比例一律不动，Skill 只改 `.wrap` 内文字。
- **仅产 HTML**：JPG 长图由用户独立只读定稿负责，不在本 Skill 范围。
- **完全本地**：不联网、不向任何外部端点发送数据、不上传用户内容。
